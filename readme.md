# FEDAGORA

##  What is Fedagora

fedagora is a decentralized social platform allowing users to create programable instances of the platform thanks an integrated API allowing developpers to personalize the behavior of their instance.

## how to setup the project

### prerequisites:

nodejs
npm
docker
docker compose

### instructions:

- `docker compose up`

- #### build:
    - `npm run build`
    - all the generated binaries will be stored in electronDist directory
- #### test:
    - `npm run test`
